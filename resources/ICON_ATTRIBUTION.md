# TeamSync icon resources

The interface icons in `icons/` are from [Lucide](https://lucide.dev/), maintained
by Lucide Icons and Contributors, with Feather-derived artwork by Cole Bemis.
The complete ISC and applicable MIT notices are in `LICENSE-Lucide.txt` and are
embedded in the executable with these assets. The TeamSync project license does
not replace these third-party permissions.

Source: https://github.com/lucide-icons/lucide/tree/c29c276f16590cf017126671535ad8c792be64d8/icons

SVG path data is preserved from that revision; whitespace was compacted and
files are named for the interface role they serve. `ThemeManager` substitutes
`currentColor` at render time and generates high-DPI light/dark icon pixmaps.

`check-white.svg` is a fixed-white variant of the Lucide check path used by
Qt's stylesheet checkbox indicator. `app.svg` is TeamSync's own application
mark, not a Lucide brand asset. `team-collaboration.svg` is an original TeamSync
illustration created for the login page. It uses editable vector shapes rather
than photographs or content cropped from the visual reference. These two
original graphics are covered by the TeamSync project license.
