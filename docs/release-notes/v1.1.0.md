# TeamSync v1.1.0 — release candidate

This source update is not yet a published binary release. The Windows GUI package is being held until the Qt SDK license edition is verified and its corresponding source materials can be included with the distribution. The latest published Windows ZIP remains available from the [Releases page](https://github.com/SudhanTheDev/TeamSync/releases/latest).

This release brings the console interface up to the GUI collaboration and recovery workflows and replaces the previous LAN transport with a shared native engine.

## Highlights

- GUI and console can host or join using the same `TEAMSYNC/3` protocol.
- Nearby-workspace discovery, incremental synchronization, chunked SHA-256-verified file transfer, cancellation, and retry/resume.
- Offline changes remain queued; stale revisions are rejected, and conflict resolution is explicit.
- Dated automatic/manual backups and recoverable conflict snapshots, with guarded whole-workspace restore.
- Table and board task views, status transitions, and drag-and-drop attachments.
- Console guest access, protected saved sign-in, background idle sync, connection status, recovery, search, and task-board actions.
- Improved sign-in behavior while background backups read live workspace files.

## Upgrade and compatibility

Update every computer before connecting it to a TeamSync v1.1.0 host. The v1.1.0 GUI and console use protocol `TEAMSYNC/3`; older JSON/binary network implementations are incompatible. Workspace record formats remain unchanged.

Back up any important workspace before upgrading. LAN hosting still requires the host application to remain open. This release is for trusted local Wi-Fi/hotspot networks; it does not add TLS, cloud synchronization, or internet hosting. A real network test is recommended because loopback tests cannot model every router, firewall, or PC.

The v1.1.0 Windows ZIP is pending the Qt license/source check described in [third-party notices](../THIRD_PARTY_NOTICES.md). No installer is planned for this release.
